MPA split starting 2027–2028 (vote needed)

  1. Which event comes first (February or March) and which is in April?
  2. Set the dates. Suggested options (WHSAA and WMEA 2027–28 calendars aren't posted yet):

    • March: Mon–Tue March 6–7 or March 13–14, 2028 (ahead of the likely late-March ACT window)
